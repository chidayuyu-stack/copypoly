# 自由变形实现与验证（1.6.0）

每个形状可使用原有自动凸包，或使用保存顶点索引和三角面连接的自由网格。自由网格不再根据每次移动后的外包面重建连接，因此一个内移顶点仍参与相邻面的绘制。坐标保持十分之一像素格点，顶点数量上限仍为 64。

凸包转网格时先三角化外表面，再将已有未连接顶点接入最近的面或边；重合的复制点暂不接入，移开后再连接。普通移动保留连接，新增控制点只细分其邻接区域；删点按邻接环补面。显式镜像会反转面绕序，旋转保持绕序。共面的内部三角边不输出为选中轮廓，真实折痕保留。

自由网格校验索引、非退化面、每条边两侧的相反绕序、单一连通表面、顶点邻接环、正体积及自交。交叉、重合、塌陷或未封闭的草稿不能提交，服务器同样校验。

网格包含性使用有向立体角；碰撞采样同时检查体素中心和三角形/AABB 的分离轴交叠，以保留薄表面并留下真正的凹槽。合并体素仍沿用最多 64 个 AABB、基础 8 等分的预算，必要时降低细分。Sable 继续读取这些实际位置的 AABB；相同点集、不同模式和面连接会得到不同的几何缓存项。

方块增加可选 `Faces`，物品增加 `PolyFaces`；没有该字段的旧数据仍按凸包读取。面索引和模式通过编辑菜单、应用包和客户端方块同步传递；编辑协议升级为 3。整形复制文本使用 `CopyPolyMesh 1` 并保存点顺序与面连接，纯坐标和选中点复制仍保持兼容。

验证结果：

- 36 项单元测试通过，覆盖固定连接的凹陷/恢复、凹槽空隙、薄网格覆盖、镜像绕序、坐标及连接往返、补面、新点接入、非法网格拒绝和从无效草稿删点恢复。
- 无 Sable 时 13 项游戏测试通过，包含带面索引的真实数据包往返、服务端校验、NBT/客户端同步、掉落物和重新放置，以及玩家碰撞中凹槽的空隙。
- 加载 Sable 2.0.6 时 18 项游戏测试通过。原生落体落在凹槽的半格高度，而相同顶点的凸包模式落在一格高度；切回自由模式重新落到半格。实际组装的凹形 Sable 结构也通过原生物体接触测试。
- 独立客户端检查通过世界拖轴、内凹及向外恢复、两种模式切换、整形复制粘贴、镜像与旋转、七种材质网格、预览、保存及重新打开；该次客户端正常保存退出。截图位于 `run/freeform-smoke/screenshots/`。

碰撞是有限分辨率的阶梯近似，细于当前体素的凹槽可能被填平；视觉顶点仍保持 0.1 像素精度。切回自动凸包会包住凹陷，属于模式本身的行为。
