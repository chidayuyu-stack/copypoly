# CopyPoly 1.9.1

适用于 Minecraft 1.21.1、NeoForge、机械动力 Create 6.0.x，可选支持 Sable 2.0.6。

## 直接在世界里编辑

潜行右键伪装多面体打开编辑器；右键目标形状，添加普通顶点（黄色）或自定义顶点（紫色）。两种顶点都能互相连线。

- **单击顶点**：按下时不弹三轴，原地松开后才选中并显示三轴。拖轴移动，默认 1 像素；按 Ctrl 为 0.1 像素。
- **按住顶点拖向另一个点**：建立连线。按下、拉线及完成连接后均不显示三轴；再次单击顶点才显示。连线没有方向，从任一端拖过去都一样；重复拖同一条线可断开。
- **连线自动分割面**：画出的线作为实际分界线，闭合区域自动成面。初次连线会保留原表面及参考位置，之后移动点仍保留连接关系，不再重建凸包。虚线表示尚未形成有效分割的连接，基础表面保留。
- **左键点击拉出的线，再按 Del**：选中的线加粗高亮，只断开连接，保留端点；实线和待完成的虚线均可选。Ctrl+Z 恢复连接及选线状态。
- **左键点击面，再按 Del**：直接删除选中的面，顶点保留。不需要切换工具。相邻三角形会合并选择，但不会越过玩家画的分界线。
- **多选至少三个顶点，点击“新建面”**：优先按已有开口的边界补面；其他选区自动排列。无需按顺序点选、切模式或记快捷键。非平面的多点面会自动拆成三角面。
- **Ctrl 点击多选 / Ctrl 左拖框选**：框选替换旧选区，空框清空选择。多点选中后一起拖轴移动；到边界时整体停止。
- **Del** 删除选中的顶点、连线或表面；**Ctrl+Z** 或“撤销”按钮撤销建点、连线、断线、移动、删面、建面等编辑。一整次拖轴只占一步，保留最近 100 步。纯选择和相机操作不进入历史。
- 左侧只显示当前选中顶点的坐标。选面时显示选面提示，避免把面与点混淆。坐标输入框聚焦时 Del 和 Ctrl+C/V 仍用于文本编辑；点击画布退出输入。

### 图中的平底凹槽

在顶面放四个内点，将它们连成小四边形，再分别连到外侧四角。顶面自动分成中间一块与外围四块；Ctrl 多选这四个内点，拖 Y 轴向下，即可得到平底、四周斜面的凹槽。删除内点或断开连接时，会根据保留的原表面与剩余连接重新生成；Ctrl+Z 可恢复。

跨越已有分界线的连线需要显式交点，不会偷偷添加顶点。无效连接不会覆盖已经有效的切面。复制出来的重合控制点/环暂时保持待完成状态，移动后再参与表面。

## 应用与红色缺口提示

点击“应用”检查表面，合法时提交服务器。没有封闭时仍可点击该按钮，实际缺少的面会用**半透明红色**标出，**5 秒后自动消失**。再次点击“应用”重新显示并计时；补面成功立即清除。提示消失不会改变草稿，也不会提交不完整碰撞。

检查依据是三角表面的闭合性，**不要求填满包围盒**。O 形、环形、贯穿孔、内部空腔及多个独立的闭合实体均可保存；设计中的孔洞不会被当成缺口。若环形结构的一片环状表面缺失，提示只覆盖该缺失区域，保留原有中心孔。

上限为 64 个顶点，坐标范围 0～16、精度 0.1 像素，最多 1344 个三角面。表面需封闭、有体积且不自交，不能有重合或零面积面。取消或 Esc 丢弃草稿；小菜单打开时 Esc 先关闭菜单。

## 其他操作

- **Ctrl+C/V** 复制选中点/追加粘贴到原坐标，保留类型和选区内部的连线，不绑定旧对象的其他点。面板“复制/粘贴”用于导出或替换整个文档，保留参考表面和连接；支持旧坐标及旧网格文本。
- “镜像 X/Y/Z”和“X/Y/Z +90°”作用于整体，中心为 `(8,8,8)`；按 Shift 反向旋转。
- “更多编辑”保留逐面重建、清空面、面工具和 F 建面等高级操作；日常加点、拉线、删面、建面无需展开。
- 世界编辑使用独立相机：WASD 飞行、空格/Shift 升降、空白处左拖平移、右拖环视、滚轮推拉，遵循游戏灵敏度及按键设置。相机不驱动玩家，退出恢复原视角。面板可以移动和最小化。

## 轮廓、碰撞与兼容

轮廓显示实际斜边，线、点、三轴及红色提示采用抗锯齿绘制。实体碰撞仍使用最多 64 个轴对齐盒近似，基础精度 2 像素，复杂形状降低细分；小于该尺度的凹陷或孔可能被近似填平。

Sable 地形和实际组装结构使用方块实体的形状，应用编辑后刷新碰撞。结构上的点、线、面选择、拖轴与红色缺口提示按当前结构姿态显示。无需安装 Copycats+，未安装 Sable 也能运行。

旧存档、物品、固定凹面和 1.7 的有向自定义连接均可读取；新连线采用无向表面分割。编辑文档随同步、存档、掉落和重新放置保存。编辑协议仍为 6，与 1.9.0 相同；新版交互请使用 1.9.1 客户端。

## API 与构建

公共接口见 [API.md](docs/API.md)，源码包为 `copypoly-1.9.1-sources.jar`，游戏只安装普通 jar。

使用 Java 21；Sable 仅为编译依赖，不会打入发布包：

```powershell
.\gradlew.bat test jar sourcesJar --no-configuration-cache -PsableJar="参考路径/sable-neoforge-1.21.1-2.0.6.jar"
.\gradlew.bat runGameTestServer --no-configuration-cache -PsableJar="参考路径/sable-neoforge-1.21.1-2.0.6.jar"
.\gradlew.bat runGameTestServer -PsableTest=true --no-configuration-cache -PsableJar="参考路径/sable-neoforge-1.21.1-2.0.6.jar"
.\gradlew.bat runClient -PlineSmoke=true -PclientRunDir=run/line-face-smoke --no-configuration-cache -PsableJar="参考路径/sable-neoforge-1.21.1-2.0.6.jar"
```

产物为 `build/libs/copypoly-1.9.1.jar`。`lineSmoke` 检查按下/单击/拖线的三轴状态、普通点双向连线、世界/预览选线 Del 与撤销、四点凹槽、默认点面 Del、无序多选新建面、红色缺口五秒消失及重新计时、闭合 O 形、撤销、复制及保存重开。`sableEditorSmoke` 检查实际移动旋转结构上的同类交互；`topologySmoke` 检查高级逐面重建及真正贯穿孔的应用和重开。
